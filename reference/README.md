# Reference Material

The original forensic workspace contains a larger experiment corpus under `../activetheory.net/experiments`. This rebuild intentionally does not duplicate that entire corpus because it is a historical reference set, not the production application.

The most relevant experiments for future modernization work include the WebGPU showcase, particle/fluid/crowd/fabric experiments, and the XR examples. When a feature is being implemented, use the forensic workspace as the reference source and copy only the required material into this project.
